## 4. 데이터 보안 양식

AdMob 과 ML Kit 는 앱에 들어 있는 SDK 라서, 이들이 Google 로 보내는 데이터도 앱이 "수집"한 것으로 신고해야 합니다.
AdMob 은 Google 이 자체 광고 목적으로 쓰므로 **"공유"에도 체크**합니다 (Google 의 AdMob 데이터 공개 문서가 "수집 및 공유"로 안내).

### 개요 질문

| 질문 | 답 | 이유 |
|---|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | AdMob(광고)과 ML Kit(동작 인식)가 Google 로 데이터를 보냄 |
| 앱에서 수집하는 모든 사용자 데이터는 전송 중에 암호화되나요? | **예** | AdMob 은 TLS, ML Kit 는 HTTPS 로 전송 |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **아니요** | 계정이 없고 개발자가 보관하는 데이터가 없음 (계정 생성 기능이 있는 앱만 필수). 광고 ID 는 사용자가 휴대폰 설정에서 직접 삭제·재설정 가능 |

### 수집·공유하는 데이터 유형 (이 4개만 선택)

모든 항목 공통: **일시적으로 처리되나요? 아니요** / **필수인가요, 선택사항인가요? 사용자가 선택할 수 없음(필수)**

| 데이터 유형 | 수집 | 공유 | 수집 목적 | 공유 목적 | 누가 보내나 |
|---|---|---|---|---|---|
| **위치 > 대략적인 위치** | ✔ | ✔ | 광고 또는 마케팅, 애널리틱스, 사기 예방·보안·규정 준수 | 광고 또는 마케팅, 애널리틱스, 사기 예방·보안·규정 준수 | AdMob (IP 주소로 대략적 위치 추정) |
| **앱 활동 > 앱 상호작용** | ✔ | ✔ | 광고 또는 마케팅, 애널리틱스, 사기 예방·보안·규정 준수 | 광고 또는 마케팅, 애널리틱스, 사기 예방·보안·규정 준수 | AdMob (앱 실행, 광고 탭·조회) |
| **앱 정보 및 성능 > 진단** | ✔ | ✔ | 앱 기능, 애널리틱스, 광고 또는 마케팅, 사기 예방·보안·규정 준수 | 광고 또는 마케팅, 애널리틱스, 사기 예방·보안·규정 준수 | ML Kit, AdMob |
| **기기 또는 기타 ID > 기기 또는 기타 ID** | ✔ | ✔ | 앱 기능, 애널리틱스, 광고 또는 마케팅, 사기 예방·보안·규정 준수 | 광고 또는 마케팅, 애널리틱스, 사기 예방·보안·규정 준수 | AdMob (광고 ID, 앱 세트 ID), ML Kit (설치별 ID) |

### 선택하지 않는 데이터 유형과 이유

Google Play 기준으로 **기기 밖으로 나가지 않는 데이터는 "수집"이 아닙니다.**

| 데이터 유형 | 선택 안 함 | 이유 |
|---|---|---|
| 정확한 위치 | ✘ | GPS·위치 권한을 쓰지 않음 (AdMob 은 IP 기반 대략적 위치만) |
| 사진 및 동영상 | ✘ | 카메라 영상은 기기 안에서 관절 좌표만 계산하고 바로 버림, 저장·전송 없음 |
| 캘린더 일정 | ✘ | 폰의 공휴일 달력을 기기 안에서만 읽음 |
| 건강 및 피트니스 | ✘ | 운동 기록은 기기 안에만 저장, 광고 요청에 넣지 않음 |
| 파일 및 문서, 오디오 | ✘ | 알람음 파일은 기기 안에서 재생만 함, 백업은 사용자가 직접 지정한 위치에 저장 |
| 개인 정보, 금융 정보, 메시지, 연락처, 웹 기록, 앱 활동 중 앱 상호작용 외 항목 | ✘ | 사용하지 않음 |

### 공개 데이터 보안 섹션에 보이는 모습 (예상)

- 서드 파티와 공유될 수 있는 데이터: 위치, 앱 활동, 앱 정보 및 성능, 기기 또는 기타 ID
- 수집되는 데이터: 위치, 앱 활동, 앱 정보 및 성능, 기기 또는 기타 ID
- 전송 중 데이터 암호화됨

## 5. 함께 작성하는 앱 콘텐츠 신고 (참고)

| 항목 | 답 |
|---|---|
| 광고 | **예, 광고 포함** (위 2항) |
| 광고 ID | 위 3항 |
| 앱 액세스 권한 | 모든 기능을 제한 없이 사용 가능 (로그인 없음) |
| 콘텐츠 등급 설문 | 폭력·성적 콘텐츠·도박·사용자 간 소통·위치 공유 모두 "아니요". 광고 관련 질문이 있으면 사실대로 "광고 포함" |
| 타겟층 | **16~17세, 18세 이상** 만 선택 권장. 13~15세를 넣으면 만 14세 미만이 포함되고, 12세 이하를 넣으면 가족 정책(광고 SDK 제한 포함) 심사가 추가됨. 개인정보처리방침의 "만 14세 미만 대상 아님"과도 맞음 |
| 건강 앱 | "활동 및 피트니스" 선택 |
| 전체 화면 인텐트 | "알람 기능이 핵심 기능" 선택 |
| 포그라운드 서비스 | `mediaPlayback` 유형: 설명 "설정한 시각에 알람음을 재생하고, 끄거나 다시 알림할 때까지 계속 울림", 중단 시 영향 "알람이 울리지 않아 사용자가 기상 시각을 놓침", 영상: 알람 설정 → 화면 끄기 → 알람이 울리며 소리 재생되는 화면 녹화 |
| 정확한 알람(USE_EXACT_ALARM) | 알람 앱이라 정책상 허용 대상. 심사 중 질문이 오면 "사용자가 설정한 시각에 울리는 알람 시계 앱" 으로 답변 |
| 금융 기능, 정부 앱, 뉴스 앱 | 해당 없음 |
