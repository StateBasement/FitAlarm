# Play Console 작성 답안: 데이터 보안 · 개인정보처리방침

Play Console > 앱 선택 > **앱 콘텐츠** 에서 아래 순서대로 입력하세요. (앱 버전 2.1.0 기준)

## 1. 개인정보처리방침

- URL: `https://github.com/StateBasement/FitAlarm/blob/main/docs/privacy-policy.md`
- 앱 안에서도 **설정 > 정보 > 개인정보처리방침** 에서 같은 페이지가 열립니다 (Google Play 는 Play Console 과 앱 안 양쪽에 방침을 요구).
- 올리기 전에 방침 문서의 `[개발자 이름]`, `[문의 이메일]` 을 실제 값으로 바꿔야 합니다.
- 저장소를 비공개로 바꾸면 이 주소가 열리지 않으니, 그 전에 방침을 공개 위치(GitHub Pages, 별도 공개 저장소, 개인 웹사이트 등)로 옮기고 앱의 주소(`SettingsPage.kt` 의 `PRIVACY_POLICY_URL`)와 Play Console 주소를 함께 바꾸세요.

## 2. 데이터 보안 양식

### 개요 질문

| 질문 | 답 | 이유 |
|---|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | 앱에 들어 있는 ML Kit 가 진단 정보를 Google 로 보냄 (SDK 가 보낸 데이터도 "수집"에 해당) |
| 앱에서 수집하는 모든 사용자 데이터는 전송 중에 암호화되나요? | **예** | ML Kit 는 HTTPS 로 전송 |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **아니요** | 계정이 없고 개발자가 보관하는 데이터가 없음 (계정 생성 기능이 있는 앱만 필수). 기기 데이터는 앱 삭제 시 삭제됨 |

### 수집하는 데이터 유형 (이 2개만 선택)

**① 앱 정보 및 성능 > 진단**

| 항목 | 답 |
|---|---|
| 수집 / 공유 | 수집됨 ✔ / 공유됨 ✘ (ML Kit 는 서드 파티에 제공하지 않음) |
| 일시적으로 처리되나요? | 아니요 |
| 필수인가요, 선택사항인가요? | 사용자가 선택할 수 없음(필수) |
| 수집 목적 | 분석, 앱 기능 |

**② 기기 또는 기타 ID > 기기 또는 기타 ID**

| 항목 | 답 |
|---|---|
| 수집 / 공유 | 수집됨 ✔ / 공유됨 ✘ |
| 일시적으로 처리되나요? | 아니요 |
| 필수인가요, 선택사항인가요? | 사용자가 선택할 수 없음(필수) |
| 수집 목적 | 분석, 앱 기능 |

(ML Kit 의 설치별 식별자와 Firebase 설치 ID. 사용자나 실제 기기를 고유하게 식별하지 않음)

> "공유됨"을 체크하지 않은 이유: ML Kit 문서가 이 데이터를 서드 파티에 보내지 않는다고 밝히고 있기 때문입니다.
> 심사에서 지적받거나 더 보수적으로 가고 싶다면 두 항목 모두 "공유됨"도 체크해도 됩니다 (앱 동작에는 영향 없음).

### 선택하지 않는 데이터 유형과 이유

Google Play 기준으로 **기기 밖으로 나가지 않는 데이터는 "수집"이 아닙니다.**

| 데이터 유형 | 선택 안 함 | 이유 |
|---|---|---|
| 사진 및 동영상 | ✘ | 카메라 영상은 기기 안에서 관절 좌표만 계산하고 바로 버림, 저장·전송 없음 |
| 캘린더 일정 | ✘ | 폰의 공휴일 달력을 기기 안에서만 읽음 |
| 건강 및 피트니스 | ✘ | 운동 기록은 기기 안에만 저장 |
| 파일 및 문서, 오디오 | ✘ | 알람음 파일은 기기 안에서 재생만 함, 백업은 사용자가 직접 지정한 위치에 저장 |
| 위치, 개인 정보, 금융 정보, 메시지, 연락처, 앱 활동, 웹 기록 | ✘ | 사용하지 않음 |

### 공개 데이터 보안 섹션에 보이는 모습 (예상)

- 서드 파티와 공유되는 데이터 없음
- 수집되는 데이터: 앱 정보 및 성능, 기기 또는 기타 ID
- 전송 중 데이터 암호화됨

## 3. 함께 작성하는 앱 콘텐츠 신고 (참고)

| 항목 | 답 |
|---|---|
| 광고 | 광고 없음 |
| 앱 액세스 권한 | 모든 기능을 제한 없이 사용 가능 (로그인 없음) |
| 콘텐츠 등급 설문 | 폭력·성적 콘텐츠·도박·사용자 간 소통·위치 공유 모두 "아니요" |
| 타겟층 | 13세 이상 (아동을 포함하면 가족 정책 심사가 추가됨) |
| 건강 앱 | "활동 및 피트니스" 선택 |
| 전체 화면 인텐트 | "알람 기능이 핵심 기능" 선택 |
| 포그라운드 서비스 | `mediaPlayback` 유형: 설명 "설정한 시각에 알람음을 재생하고, 끄거나 다시 알림할 때까지 계속 울림", 중단 시 영향 "알람이 울리지 않아 사용자가 기상 시각을 놓침", 영상: 알람 설정 → 화면 끄기 → 알람이 울리며 소리 재생되는 화면 녹화 |
| 정확한 알람(USE_EXACT_ALARM) | 알람 앱이라 정책상 허용 대상. 심사 중 질문이 오면 "사용자가 설정한 시각에 울리는 알람 시계 앱" 으로 답변 |
| 금융 기능, 정부 앱, 뉴스 앱 | 해당 없음 |
